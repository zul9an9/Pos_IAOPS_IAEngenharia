# DevOps

Prompts para operações, SRE, observabilidade, incidentes, infraestrutura, dados e segurança operacional.

## Prompts

1. [triagem-de-pods](triagem-de-pods/) — identifica pods problemáticos, cruza status/eventos/logs e recomenda próxima ação.
2. [nota-de-triagem](nota-de-triagem/) — transforma alertas crus em notas operacionais padronizadas.
3. [analise-de-causa-raiz-cerebro](analise-de-causa-raiz-cerebro/) — constrói uma hipótese causal a partir de configuração, métricas e logs.
4. [decisao-de-contrapressao-relay](decisao-de-contrapressao-relay/) — compara opções de proteção contra sobrecarga e escolhe uma combinação justificável.
5. [migracao-forge-event-driven](migracao-forge-event-driven/) — encadeia diagnóstico, plano, detalhamento e reversibilidade para a migração do Forge.
6. [refino-networkpolicy-sentinel](refino-networkpolicy-sentinel/) — corrige e refina uma NetworkPolicy por rodadas de crítica e verificação.
