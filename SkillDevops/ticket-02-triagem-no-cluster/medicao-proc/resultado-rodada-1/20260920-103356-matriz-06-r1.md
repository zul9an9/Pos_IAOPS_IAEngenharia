---

O diretório de trabalho está vazio (só contém `.claude`) — não há um projeto de aplicação para eu ler porta, endpoints de saúde, variáveis de ambiente etc., e a skill proíbe inventar esses valores. Preciso de algumas informações antes de gerar o manifesto:

1. **Projeto/aplicação**: tem um repositório local ou URL para eu clonar e ler o código (porta que o processo escuta, endpoints de health, variáveis de ambiente)? Ou você vai me passar esses dados diretamente?
2. **Identificação**: nome do `cliente`, `ambiente` (ex: prod/staging) e `componente`/`app`.
3. **Imagem**: registry/imagem e versão (ex: `registry.metacortex.io/<cliente>/<app>:<versao>`).
4. Se não houver projeto para eu ler: porta do container, se existe endpoint de readiness/liveness (e se algum toca banco), variáveis de ambiente que o código espera, quais são credenciais, e requests/limits de CPU/memória desejados.

Com isso eu preencho o modelo (`ServiceAccount` + `Deployment` + `Service` + `PDB`) e rodo o `conferir.py` para validar contra o padrão da Metacortex antes de te entregar.
